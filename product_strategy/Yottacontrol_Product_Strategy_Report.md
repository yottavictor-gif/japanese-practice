# Yottacontrol 巨控自動化：產品開發與競爭力提升建議報告 (更新版)

## 1. 執行摘要 (Executive Summary)
本報告旨在為 Yottacontrol 提供具備高度競爭力的產品開發路徑。核心戰略為：**「硬體為骨、軟體為魂、方案為引」**。透過將現有的穩定硬體（無線 I/O）與現代化的工業物聯網（IIoT）軟體技術整合，突破歐美市場門檻，並在與競爭對手（如：泓格）的對抗中取得差異化優勢。

---

## 2. 市場與競品深度分析
*   **競爭對手 (泓格 WISE/PMC)：** 強項在於「Web-based 免程式邏輯」與「完整工業協定」。但其缺點在於系統較為封閉且硬體外觀較傳統。
*   **Yottacontrol 現狀：** 擁有極佳的 **無線通訊穩定性** 與 **高性價比**。目前與 HomeAssistant (HIPC) 的整合已具備優勢，但缺乏「開箱即用」的行業方案與「自有雲端生態」。
*   **技術缺口：** 歐美市場極度重視 **OPC UA** 與 **MQTT 加密**，現有 MCU 硬體難以承載，需透過「邊緣主機」或「雲端平台」實現轉化。

---

## 3. 短期：軟性方案包裝 (Soft Solution Kits) —— 快速增加銷量
**目標：** 讓客戶「看見結果就想買」，降低 SI 客戶的進入門檻。

*   **開發建議：** 針對三大行業開發預設的 **HomeAssistant (HIPC) 儀表板範本**。
    1.  **智慧農業監控套件：** A-52x (WiFi) + 土壤/環境感測器，搭配自動灌溉邏輯範本。
    2.  **EV 充電樁負載管理套件：** A-18xx (Ethernet) + 電錶整合，搭配動態限流監控 Dashboard。
    3.  **節能監測方案 (EMS)：** IOT-9xx + A-10xx，預設好電表讀取與趨勢分析圖表。
*   **執行：** 建立標準化的「行業應用包」供官網下載，帶動現有 I/O 模組销售。

---

## 4. 中期：邊緣運算免程式核心 (Edge Logic Master) —— 提升競爭力
**目標：** 打造「WISE-Killer」產品，解決低階設備無法跑 Web 邏輯的問題。

*   **開發建議：** 升級 **A-9N GUI (邊緣運算器)** 的韌體功能。
    1.  **內建圖形化邏輯 (No-Code)：** 在 A-9N 的 Linux 系統上整合 Node-RED 或 Web 編輯介面。
    2.  **OPC UA 橋接器：** 由 A-9N 統一讀取下方所有 Modbus 設備，並轉化為 OPC UA Server 對接歐美系統。
    3.  **MQTT Sparkplug B 支援：** 實現設備的「隨插即用」。

---

## 5. 詳細計劃：Yotta Cloud / SaaS 雲端平台
**目標：** 建立訂閱制收入，利用 AI 協助開發，解決無軟體團隊的困境。

*   **技術架構：**
    *   **基礎平台：** FUXA (Web SCADA) + EMQX (MQTT Broker)。
    *   **部署方式：** Docker-Compose 全容器化部署於雲端 VPS。
*   **AI 協作流程：** 利用 Google Gemini/ChatGPT 產出 FUXA 轉換腳本與運維 Bash 腳本（參閱附錄 SOP）。
*   **商業模式：**
    *   初期人工開通權限，按設備數量與資料保存時長進行訂閱收費。
    *   提供「Yotta 雲端代管服務」，減少客戶架站成本。

---

## 6. 技術路徑圖 (Roadmap)
1.  **Q1 (方案化)：** 完成三大行業軟性方案包裝。
2.  **Q2 (邊緣化與雲端原型)：** 啟動 A-9N 軟體升級；建立 Yotta Cloud Docker 原型。
3.  **Q3 (SaaS 化與國際化)：** 推出雲端訂閱服務；利用 OPC UA 進攻歐美市場。
4.  **Q4 (AI 自主維護)：** 建立完整的 AI 輔助技術支援流程，提升售後效率。
